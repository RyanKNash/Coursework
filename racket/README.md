# Racket Assignments

Collection of Racket coursework files focused on recursion, functional programming, mathematical reasoning, Peano arithmetic, Boolean encodings, SAT/truth-table concepts, and induction proofs.

## What It Covers

- Recursive list processing without loop constructs.
- Polynomial evaluation and coefficient-list operations.
- Peano natural number representation and arithmetic.
- Boolean-list encodings of integers.
- Truth-table and SAT-solver foundations.
- Recursive summations and proof-by-induction exercises.
- Built-in RackUnit test suites for assignment validation.

## Key Files

| File | Purpose |
| --- | --- |
| `lists.rkt` | Recursive list and polynomial exercises with RackUnit tests. |
| `peano.rkt` | Peano arithmetic definitions including zero, successor, predecessor, addition, multiplication, and comparison. |
| `sat_solver.rkt` | Boolean encoding and SAT/truth-table assignment work. |
| `induction.rkt` | Recursive functions paired with written induction proofs. |

## Run

With Racket installed, run an individual assignment file:

```bash
racket lists.rkt
racket peano.rkt
racket sat_solver.rkt
racket induction.rkt
```

From PowerShell:

```powershell
racket .\lists.rkt
```

## Concepts Demonstrated

- Functional programming in Racket
- Recursion-first problem solving
- Symbolic data representation
- Mathematical induction
- Unit testing with `rackunit`
- Boolean and binary representations
- Foundations of satisfiability solving

## Notes

These files preserve the original coursework prompts and test scaffolding. The assignment constraints emphasize recursive solutions and avoid loop constructs.
